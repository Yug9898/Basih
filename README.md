# Basih downloads

Download [Basih for Mac](https://github.com/Yug9898/Basih/raw/refs/heads/main/Basih-for-Friend.zip) or [Basih for Windows](https://github.com/Yug9898/Basih/raw/refs/heads/main/Basih-for-Windows.zip).

Mac: unzip, then double-click **Install Basih.command**. Later updates take one click in **Settings → Updates → Update Basih**.

Windows: unzip, then double-click **Install Basih.cmd**.

Each download starts with an empty ledger. Your records are stored locally on your computer.
