# Basih downloads

Mac release **1.0002.00.37** supports **M1-or-later Macs running macOS 26 or later**. The download contains the native My Basih app. Intel Macs, older macOS versions, the legacy app and Windows are not supported by this release.

[Download Basih for Mac](https://github.com/Yug9898/Basih/raw/refs/heads/main/Basih-for-Friend.zip)

Unzip and double-click **Install Basih.command**. The installer checks your Mac and macOS before replacing an app. Existing local entries, People balances, backups and Keychain credentials stay on your Mac. Existing supported installations can upgrade to My Basih.

This update:

- Sends completed no-payment settlements directly to History. Cleared entries leave the open People list; spending and bank balances stay unchanged. Settlement records cannot be deleted to accidentally restore a cleared balance. Connected settlements still require both people to agree.
- Updates the Activity split editor with **You**, your people, and **Other people**. Selected participants share equally, with exact cents; edit an amount for custom shares. Existing custom splits are preserved.
- Adds a **Week containing** calendar to inspect a particular week's figures and dates alongside running averages and totals.
- Restores account comparison with **force-click and hold for three seconds**, with progressively slower haptic pulses. Right-click and accessibility actions remain available.
- Preserves the native glass interface and the Review, History, account-removal and bank-reconnection improvements from the previous release.

To restore a backup, open **Settings → Backups → Choose backup…**, select the SQLite backup and confirm its passcode. A safety backup is created first; the selected original is retained. A backup moved to another Mac may require reconnecting bank or merchant-search credentials.

These apps are ad-hoc signed, not notarized. macOS may require approval in Privacy & Security on first launch. Touch ID may be unavailable without distribution provisioning; passcode unlock is supported.

Downloads contain no personal ledgers, backups or private API keys. Older artifacts remaining in this repository are historical downloads, not supported current releases.
